# Common Tasks Agent

Use this guide for everyday feature work.

## Checklist

- Read the relevant docs before editing code.
- Add or reuse a contract before adding a concrete dependency.
- Keep functions short and names direct.
- Add focused tests for new behavior.
- Update examples when the public usage pattern changes.

## Common Workflows

- Add a route: read `.agents/fastapi-routes.md`.
- Add a repository: read `.agents/database.md`.
- Add an API client: read `.agents/external-apis.md`.
- Add a parser or writer: read `.agents/excel.md`.
- Change structure: read `.agents/architecture.md`.
